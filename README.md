Python code for the four tasks in SD202 Assessment 1. Each task is in its own folder.

## Tasks

### Task 1 - Detective (`detective/`)

`task1_detective.py`

Work out which murder scenario is most likely. Each scenario is scored by adding the room value and the tool value, using two dictionaries so the values are not hard coded. The scenarios are then sorted from highest score to lowest.

### Task 2 - Sports Emojis (`sports-emoji/`)

`task2_sportsemoji.py`

Asks the user for five sports keywords separated by commas and converts each one into an emoji. Keywords that are not in the dictionary become a confusion emoji. If there are not exactly five keywords, or if a keyword is repeated, an error message show and the user is asked to enter them again.

### Task 3 - File Formatting (`file-formatting/`)

`task3_file-formatting.py`, `student_record_v1.txt`, `student_record_v2.txt`

Reads the unstructured records in `student_record_v1.txt`, splits the 25 lines into five categories, generates an email for each student in the format `firstname_lastname@yoobeecolleges.com`, and writes the tidied records to `student_record_v2.txt`

**Note:** run this one from inside the 'file-formatting' folder, because the file paths are relative.

### Task 4 - Code Analysis (`code-analysis/`)

`task4_code-analysis.py`

The code in the assessment, kept unchanged for analysis. The written analysis is in the Word Document. The misspelt function name `sequnece_checker` is part of the original code and has been left as it was given.

## Running the code

Python 3 is required. From the folder for the task:

```
python task1_detective.py
```
